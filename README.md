# Calculator

A simple and interactive calculator built using HTML, CSS, and JavaScript. It performs basic arithmetic operations with a clean, dark-themed user interface.

## Live Demo

[Click here to use the calculator](https://calculator-vert-rho-81.vercel.app/)

## Features

* Addition, subtraction, multiplication, and division.
* Real-time calculation display.
* Interactive buttons with hover effects.
* Clear button to reset calculations.
* Local storage to save calculations.
* Responsive user interface.

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Local Storage
